# Участие в разработке

Спасибо за интерес к WT Translator Local!

## Обсудить проблему

Создайте Issue: укажите ОС, архитектуру процессора, версию приложения, шаги
воспроизведения и ожидаемый результат. Для ошибок локализации достаточно
небольшого искусственного CSV-примера. Не прикладывайте личные настройки,
всю папку игры или секреты.

## Предложить изменение

1. Сделайте fork и создайте ветку для изменения.
2. Установите .NET SDK 10 и выполните команды из README.
3. Внесите изменение. Для изменения парсера или патчера добавьте тест,
   проверяющий реальное поведение, включая сохранение формата CSV.
4. Запустите `dotnet build -c Release` и `dotnet test -c Release`.
5. Проверьте соответствующий сценарий в GUI и обновите документацию,
   если изменилось поведение.
6. При изменении приложения обновите ZIP-файлы командой `./scripts/update-binaries.sh`
   на macOS и включите папку `binaries/` в коммит. Мейнтейнер публикует обновление
   в GitHub и GitLab командой `./scripts/push-all.sh`.
7. Откройте Pull Request с описанием проблемы, решения и выполненных проверок.

Проект использует C#, Avalonia и xUnit. Приложение работает локально;
добавление сетевых сервисов требует отдельного обсуждения.
